Go SDK v2

A typed client for the v2 REST API, for Go 1.18+.

Install

terminal bash 
go get github.com/godzilla-io/sdk-go

Create a client

main.go go 
package main

import (
	"os"
	"github.com/godzilla-io/sdk-go"
)

func main() {
	client := godzilla.NewClient(os.Getenv("GODZILLA_API_KEY"))
}

Create a pipeline

Maps directly onto the Pipelines endpoint — see the Building your first pipeline guide for the concepts.

create_pipeline.go go 
pipeline, err := client.Pipelines.Create(ctx, &godzilla.CreatePipelineRequest{
	Name:                    "ingest-orders",
	SourceConnectorID:       "conn_pg_orders",
	DestinationConnectorID:  "conn_snowflake_dw",
})
if err != nil {
	panic(err)
}

Handling failed events

Wraps the replay action described in Handling errors & retries:

replay.go go 
err := client.Events.Replay(ctx, "evt_8f2c1a90")
if err != nil {
	panic(err)
}
Context support

All client methods accept a context.Context parameter for timeout, cancellation, and request tracing.
