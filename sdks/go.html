Go SDK v2

A fully typed client for the v2 REST API for Go 1.19+.

Install

terminal bash 
go get github.com/godzilla/sdk-go

Create a client

main.go go 
package main\n\nimport (\n	"os"\n	sdk "github.com/godzilla/sdk-go"\n)\n\nfunc main() {\n	client := sdk.NewClient(\n		sdk.WithAPIKey(os.Getenv("GODZILLA_API_KEY")),\n	)\n
}

The SDK provides typed methods for publishing events to Godzilla connectors:

{{ds:component/code-block|filename=main.go|language=go|code=event, err := client.Events.Publish(ctx, &sdk.PublishEventRequest{\n ConnectorID: "conn_kafka_orders",\n Data: map[string]interface{}{\n "order_id": "12345",\n "amount": 99.99,\n },\n})\nif err != nil {\n panic(err)\n}}}
Context-aware cancellation

All SDK methods accept context.Context for timeouts and cancellation, following Go best practices.
