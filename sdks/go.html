Go SDK v2

A typed client for the v2 REST API, for Go 1.18+.

Install

terminal bash 
go get github.com/godzilla/sdk-go

Create a client

main.go go 
package main\n\nimport (\n\t\"os\"\n\t\"github.com/godzilla/sdk-go\"\n)\n\nfunc main() {\n\tclient := sdk.NewClient(os.Getenv(\"GODZILLA_API_KEY\"))\n
}

Streaming events

The SDK includes an event-streaming consumer for subscribing to events in real time:

{{ds:component/code-block|filename=main.go|language=go|code=consumer := client.Events.NewStreamConsumer(ctx, pipelineID)\ndefer consumer.Close()\n\nfor {\n\tevent, err := consumer.Next(ctx)\n\tif err != nil {\n\t\tlog.Fatal(err)\n\t}\n\t// handle event\n}}}
Context-aware throughout

Every method accepts a context.Context parameter for cancellation and timeout control, following Go best practices.
