Installation

Godzilla has no server to install — it's a hosted platform you reach over the REST API, either directly or through an SDK.

Option A: Use an SDK

terminal bash 
npm install @godzilla/sdk
# or
pip install godzilla-sdk

Full setup for each is in Node.js SDK and Python SDK.

Option B: Call the API directly

No install needed — every endpoint in the API reference is a plain HTTPS request.

terminal bash 
curl https://api.godzilladocs.dev/v2/pipelines \
  -H "Authorization: Bearer $GODZILLA_API_KEY"
Next

Either way, you'll need an API key before you can make a request — that's covered in Authentication, next.
