Authentication

Every request to the Godzilla API is authenticated with a bearer API key.

Getting an API key

Generate one from your workspace settings. Keys are scoped to a single workspace and inherit the standard rate limit described in Limits, quotas & errors.

Using the key

terminal bash 
curl https://api.godzilladocs.dev/v2/pipelines \
  -H "Authorization: Bearer $GODZILLA_API_KEY"
Never expose a key client-side

API keys carry full workspace access. Keep them server-side only — never embed one in a mobile app, browser bundle, or public repository.

Verifying webhook requests

Incoming webhook deliveries are authenticated differently: by a signed X-Godzilla-Signature header rather than your API key.
