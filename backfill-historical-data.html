Backfill historical data

When connecting a new destination to an existing data source, you often need to load historical data to catch up with current events. This recipe shows how to backfill a destination safely without duplicating ongoing events.

The challenge

Your source system has accumulated months or years of data. You want to:

  • Load all historical data into a new destination
  • Continue receiving new events without gaps or duplicates
  • Know when the backfill is complete
Backfill timing

The key is to backfill before events reach the new destination in the live pipeline, or to use a separate backfill pipeline with a different destination so live and historical data don't conflict.

Approach: Two pipelines

Run two pipelines in parallel:

  1. Historical backfill — a one-time pipeline that reads all past data from your source (filtered by a date range or cursor position) and writes it to the destination.
  2. Live pipeline — your normal, ongoing pipeline that picks up from where backfill stops and continues in real time.

Setting up the backfill pipeline

Create a new pipeline with the same source and destination connectors, but add a source filter to limit events to your historical window:

{{ds:component/code-block|filename=backfill-pipeline.config.json|language=json|code={ "name": "backfill-orders-2024", "source": { "connector": "postgres-prod", "query": "SELECT * FROM orders WHERE created_at < '2024-06-01'" }, "destination": "analytics-warehouse" }}}

Once the backfill completes, your live pipeline can start fresh (or resume from the backfill checkpoint) and add only new events.

Monitoring and handoff

  • Check the Run Details page to see when the backfill finishes.
  • Verify row counts in your destination to confirm all historical data arrived.
  • Start or resume your live pipeline once backfill is complete.
Watch for timeouts

Very large backfills (millions of rows) may take hours. Use a destination that supports bulk loading, and consider breaking the backfill into smaller date windows if the pipeline times out.
