Events endpoint v3 Stable

Query and replay events that have flowed through a pipeline.

List events

GET /v3/pipelines/{pipeline_id}/events — cursor-paginated, filterable by type, status, and occurred_at range. v3 adds status filtering for better event lifecycle visibility.

Name Type Required Description
typestringNoFilter to a single event type, e.g. order.created.
statusstringNoFilter by event status: success, failed, pending.
sincestringNoISO-8601 timestamp lower bound on occurred_at.
cursorstringNoOpaque pagination cursor from a previous response's next_cursor.

Replay an event

POST /v3/events/{id}/replay — re-runs an event that failed or exhausted retries. v3 allows selective replays for any event, not just dead-lettered ones, with automatic retry logic.

Platform events

Lifecycle notifications like pipeline.started and connector.error are not returned by this endpoint — subscribe to them through the Webhooks endpoint instead.

Migrating from v2?

v2 is no longer supported. See the v2 → v3 migration guide for breaking changes and upgrade steps.
