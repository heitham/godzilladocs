Transforms endpoint v2

Create and list transform steps attached to pipelines. Transforms process and mutate events in flight before they reach the destination connector. Base URL: https://api.godzilladocs.dev/v2.

Create a transform step

POST /v2/pipelines/{pipeline_id}/transforms

Name Type Required Description
typestringYesOne of reshape, filter, or enrich.
configobjectYesType-specific configuration object defining rules, mappings, or fields.
orderintegerNoZero-indexed execution order within the pipeline. Appended to the end if omitted.
create-transform.sh bash 
curl -X POST https://api.godzilladocs.dev/v2/pipelines/pl_ingest_orders/transforms \
  -H "Authorization: Bearer $GODZILLA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "reshape",
    "config": {
      "mappings": {
        "id": "payload.order_id",
        "total_price": "payload.amount_cents"
      },
      "remove": ["payload.internal_notes"]
    },
    "order": 0
  }'

List transform steps

GET /v2/pipelines/{pipeline_id}/transforms — returns the ordered list of transform steps configured for the specified pipeline.

Name Type Required Description
cursorstringNoOpaque pagination cursor from a previous response's next_cursor.
limitintegerNoMaximum number of transform steps to return per page (default 50, max 100).
transforms-list.json json 
{
  "data": [
    {
      "id": "tr_7a9f12b",
      "type": "filter",
      "order": 0,
      "config": { "condition": "payload.amount_cents > 0" }
    },
    {
      "id": "tr_8c4e33a",
      "type": "reshape",
      "order": 1,
      "config": {
        "mappings": { "id": "payload.order_id", "total_price": "payload.amount_cents" },
        "remove": ["payload.internal_notes"]
      }
    }
  ],
  "next_cursor": null,
  "has_more": false
}

Transform types

Godzilla supports three transform types: filter to evaluate conditions and discard unmatched records, reshape to reorganize fields and strip private keys, and enrich to append metadata. For comprehensive examples, see the Transforming events in flight guide.

Sequential execution

Transform steps execute sequentially by order. Each step receives the modified payload from the preceding step. If an event fails a transform step, it is retried and routed according to your error-handling policy.
