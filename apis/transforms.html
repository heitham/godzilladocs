Transforms endpoint v2

Manage transform steps — the data manipulation and filtering logic that runs between a pipeline's source connector and destination.

Create a transform step

POST /v2/pipelines/{pipeline_id}/transforms

Name Type Required Description
pipeline_idstringYesUnique identifier of the pipeline containing this transform.
namestringYesHuman-readable name for the transform step.
typestringYesOne of filter, map, aggregate, or custom.
configobjectYesType-specific configuration. For filter, include a condition expression. For map, include a fields object defining the output schema.
orderintegerNoPosition in the transform pipeline (0-indexed). If omitted, the transform is appended to the end.
create-transform.sh bash 
curl -X POST https://api.godzilladocs.dev/v2/pipelines/pipe_demo/transforms \\\n  -H \"Authorization: Bearer $GODZILLA_API_KEY\" \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"name\": \"filter-active-users\",\n    \"type\": \"filter\",\n    \"config\": { \"condition\": \"status == \\\"active\\\"\" }\n  }'

List transforms

GET /v2/pipelines/{pipeline_id}/transforms — returns a paginated list of all transform steps in the pipeline, ordered by their execution sequence.

list-transforms.sh bash 
curl -X GET https://api.godzilladocs.dev/v2/pipelines/pipe_demo/transforms \\\n  -H \"Authorization: Bearer $GODZILLA_API_KEY\"

Transform execution order

Transforms execute sequentially in the order defined by their order field. The data output from one transform becomes the input to the next. Use the order parameter when creating or updating a transform to reorder the pipeline without recreating every step.

Order matters

Reordering transforms changes the data that downstream steps see. A filter applied early will reduce the volume seen by later aggregate or map steps. Test carefully in a non-production pipeline first.

Get a single transform

GET /v2/pipelines/{pipeline_id}/transforms/{transform_id} — fetch details of a specific transform step, including its configuration and execution status.
