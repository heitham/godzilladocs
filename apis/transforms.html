Transforms endpoint v2

Create and manage transform steps attached to pipelines. Transforms modify events in flight as they move from source to destination. See the Transforming events in flight guide for conceptual details and examples.

Create a transform step

POST /v2/pipelines/{pipeline_id}/transforms

Name Type Required Description
typestringYesOne of filter, reshape, or enrich.
conditionstringNoBoolean expression evaluated against incoming event (required for filter).
mappingobjectNoKey-value mapping of target field names to expressions (required for reshape).
fieldsobjectNoKey-value metadata dictionary to append to payload (required for enrich).
positionintegerNoZero-indexed execution order in pipeline. Defaults to appending at the end.
create-transform.sh bash 
curl -X POST https://api.godzilladocs.dev/v2/pipelines/pl_ingest_orders/transforms \
  -H "Authorization: Bearer $GODZILLA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "filter",
    "condition": "payload.status == '\''completed'\''"
  }'

List transform steps

GET /v2/pipelines/{pipeline_id}/transforms — returns the ordered list of transform steps configured on the pipeline.

transforms-list.json json 
{
  "data": [
    {
      "id": "tr_f18e9a2b",
      "type": "filter",
      "condition": "payload.status == 'completed'",
      "position": 0
    },
    {
      "id": "tr_r73c4d11",
      "type": "reshape",
      "mapping": {
        "order_id": "payload.id",
        "total_amount": "payload.amount_cents / 100"
      },
      "position": 1
    }
  ]
}

Transform types

Godzilla supports three transform types that can be chained together:

  • filter — evaluates a boolean condition; drops events that evaluate to false.
  • reshape — maps, renames, and calculates derived payload fields.
  • enrich — injects static metadata or dynamic platform values (e.g. $now).
In-flight execution

Adding or modifying transform steps creates a new version of the pipeline. Events currently in flight finish processing on the pipeline version they started on.
