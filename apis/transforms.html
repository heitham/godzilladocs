Transforms endpoint v2

Create and manage transform steps that reshape, filter, and enrich events as they pass through a pipeline.

Create a transform

POST /v2/transforms

Name Type Required Description
pipeline_idstringYesID of the pipeline this transform belongs to.
namestringYesHuman-readable transform step name.
typestringYesOne of filter, map, enrich, or flatten.
configobjectYesType-specific configuration. See transform types below.
orderintegerNoExecution order within the pipeline; auto-incremented if omitted.

List transforms

GET /v2/transforms?pipeline_id={id} — cursor-paginated, see Rate limits & errors for the pagination envelope.

Transform types

filter

Discard events that don't match a condition.

  • expression (string, required): A condition expression evaluated against the event. Example: event.status == 'active'

map

Reshape or extract fields from an event.

  • template (object, required): A template object describing the desired output shape. Use {{event.field}} syntax for substitution.

enrich

Add or update fields by joining with external data.

  • connector_id (string, required): The lookup connector (usually a database).
  • query (string, required): The lookup query, parameterized with :event.field.
  • merge_key (string, required): The event field to merge results into.

flatten

Unnest nested arrays or objects into multiple events.

  • path (string, required): The nested field path to flatten. Example: event.items
Transform order matters

Transforms execute in the order specified by the order field. Changing order on a running pipeline takes effect on the next batch of events.
