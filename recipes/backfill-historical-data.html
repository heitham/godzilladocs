Backfill historical data

When you need to reload historical data into your destinations, a backfill pipeline lets you efficiently process past events without affecting your live pipeline.

Use cases

  • Recovering from a failed connector or destination issue
  • Loading historical data after adding a new destination
  • Correcting transformed data with an updated transformation logic
  • Populating a new data warehouse or analytics system

Best practices

When backfilling data:

  • Create a dedicated backfill pipeline to avoid impacting live traffic
  • Use time-range filtering to process data in batches
  • Monitor the backfill progress and watch for errors
  • Test with a small date range before running the full backfill
