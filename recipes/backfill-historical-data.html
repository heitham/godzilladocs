Backfill historical data

When you create a new pipeline, you often need to load historical data from your source connector. This recipe walks you through backfilling data using time-window cursors and batch operations.

Overview

Backfilling is useful when:

  • You're connecting a new data source for the first time
  • You need to replay events from a specific time period
  • You want to synchronize historical records without triggering live change detection

Prerequisites

  • A source connector that supports time-based cursors
  • A destination connector ready to receive the backfilled data
  • A pipeline with both connectors configured

Steps

1. Identify the time window

Determine the start and end dates for your backfill. For example, if your source system started recording data on January 1, 2023, you would backfill from that date to today.

2. Configure the cursor

Most connectors track position using cursors. For time-based sources, you can set the cursor to your start date using the Events endpoint or your SDK.

3. Run the backfill

Execute the pipeline and monitor its progress. If your source supports pagination, the pipeline will automatically fetch all pages within your time window.

4. Verify the backfill

Query your destination system to confirm all historical records arrived correctly. Use the Events endpoint to inspect the events that flowed through the pipeline.
