Security & compliance overview

\n

How Godzilla protects data moving through your pipelines.

\n\n

Encryption

\n

All API traffic requires TLS 1.2+. Connector credentials are encrypted at rest and are never returned in full by any endpoint after creation.

\n\n

Credential handling

\n

See Authentication for API key handling, and Connectors endpoint for connector credential rotation.

\n\n
\n
Least privilege
\n

We recommend scoping every source connector's credentials to read-only access, as described in the Connecting a data source guide.

\n
\n\n

Data residency

\n

Events are processed in the region your workspace was created in and are not replicated across regions by default.

\n\n

Reporting a vulnerability

\n

Contact the team through Support / Contact — do not file security reports as public issues.
