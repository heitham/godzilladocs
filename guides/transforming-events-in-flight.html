Transforming events in flight

As events flow through your Godzilla pipeline, you often need to modify them to match downstream system requirements, remove sensitive data, or add context. This guide walks you through the transformation patterns available in Godzilla.

Overview

Event transformation happens at three key points in a pipeline:

  • At the source: Select and map fields from the incoming event
  • In transit: Apply filters, enrichments, and reshaping logic
  • At the destination: Format the event for the target system

Reshaping events

Reshaping allows you to restructure event payloads—flattening nested objects, combining fields, or splitting a single event into multiple events. Use the transformation builder to:

  • Map source fields to new names and paths
  • Create new calculated fields from existing data
  • Flatten or nest objects as needed

Filtering events

Filters determine which events proceed through the pipeline and which are dropped. Apply conditions based on:

  • Event field values (e.g., only process orders over $100)
  • Event age or timing
  • Presence or absence of required fields

Filtered-out events are tracked in your pipeline metrics so you can monitor whether your filter rules are working as expected.

Enriching events

Enrichment adds context to events using external data sources or internal lookups. Common enrichment patterns include:

  • Looking up customer details from a database or API
  • Adding geolocation data from IP addresses
  • Appending feature flags or A/B test assignments

Enrichment happens synchronously—the pipeline waits for the lookup to complete before forwarding the event.

Chaining transformations

Transformations can be stacked to apply multiple operations to a single event. The order matters: filters typically come first (to avoid processing events you don't need), followed by reshaping, then enrichment.

Monitoring transformed events

After applying transformations, use the pipeline inspector to:

  • Preview the shape of transformed events before publishing
  • Check filter pass/fail rates in real time
  • Track enrichment latency and failure counts
