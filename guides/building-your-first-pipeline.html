Building your first pipeline

On this page
  • Create a source connector
  • Create a destination connector
  • Create the pipeline
  • Next steps

This guide walks through creating a pipeline end to end: a source connector, a destination connector, and the pipeline that ties them together.

Before you start

You'll need an API key. See Authentication in Getting Started if you don't have one yet.

1. Create a source connector

We'll pull orders from Postgres. See Connectors for the full catalog of types.

Using curl

create-source.sh bash 
curl -X POST https://api.godzilladocs.dev/v2/connectors \\\\\\\\\\\\n  -H "Authorization: Bearer $GODZILLA_API_KEY" \\\\\\\\\\\\n  -d '{"type":"postgres","direction":"source","config":{"connection_string":"postgres://..."}}'

Using Go

main.go go 
package main\\\\n\\\\nimport (\\\\n\\\\t"context"\\\\n\\\\t"fmt"\\\\n\\\\t"os"\\\\n\\\\n\\\\t"github.com/godzilla-sh/godzilla-go"\\\\n)\\\\n\\\\nfunc main() {\\\\n\\\\tclient := godzilla.NewClient(\\\\n\\\\t\\\\tos.Getenv("GODZILLA_API_KEY"),\\\\n\\\\t)\\\\n\\\\n\\\\tconnector, err := client.Connectors.Create(context.Background(), &godzilla.CreateConnectorRequest{\\\\n\\\\t\\\\tType:      "postgres",\\\\n\\\\t\\\\tDirection: "source",\\\\n\\\\t\\\\tConfig: map[string]interface(){\\\\n\\\\t\\\\t\\\\t"connection_string": "postgres://...",\\\\n\\\\t\\\\t},\\\\n\\\\t})\\\\n\\\\tif err != nil {\\\\n\\\\t\\\\tfmt.Fprintf(os.Stderr, "Error: %v\\\\n", err)\\\\n\\\\t\\\\tos.Exit(1)\\\\n\\\\t}\\\\n\\\\n\\\\tfmt.Printf("Created source connector: %s\\\\n", connector.ID)\\\\n}

3. Create the pipeline

Full request/response details are in the Pipelines endpoint reference.

Using curl

create-pipeline.sh bash 
curl -X POST https://api.godzilladocs.dev/v2/pipelines \\\\\\\\\\\\n  -H "Authorization: Bearer $GODZILLA_API_KEY" \\\\\\\\\\\\n  -d '{"name":"ingest-orders","source_connector_id":"conn_pg_orders","destination_connector_id":"conn_snowflake_dw"}'

The pipeline starts in draft state. Activate it once you're ready to start processing events.
