Quotas & billing v2

Godzilla accounts operate under usage quotas determined by your plan tier. Quotas apply at the workspace level across API request throughput, monthly event volume, and concurrent pipeline resources.

Plan tiers

Each workspace is assigned to a tier that dictates default rate limits and monthly event capacities.

Plan Rate limit Monthly events Active pipelines Support SLA
Starter 100 req / min 50,000 3 Community
Standard 1,000 req / min 1,000,000 25 1 business day
Enterprise Custom (10,000+ req / min) Custom / Unlimited Unlimited 24/7 dedicated SLA

What happens when you exceed a quota

Exceeding limits is handled differently depending on whether you exceed a per-minute API request rate or a monthly event volume quota.

API rate limits (HTTP 429)

If your application sends more requests in a one-minute window than your tier allows, the API returns a 429 Too Many Requests status code. Responses include a Retry-After header indicating how many seconds to wait before resuming requests. See Rate limits for header details and retry strategies.

Monthly event quotas

Monthly event usage resets on the first day of your billing cycle. When approaching or exceeding event limits:

  • 80% and 100% threshold alerts: Account admins receive email notifications and webhook lifecycle events (workspace.quota_warning) when approaching your limit.
  • Standard plan overages: On the Standard tier, pipelines continue running without interruption. Overage events are billed at $0.15 per 10,000 events on your next invoice.
  • Starter plan cap: Starter tier workspaces pause pipeline ingestion once the 50,000 event limit is reached until the next billing cycle or an upgrade to Standard.

Resource limits (pipelines and connectors)

If you attempt to create more active pipelines or connectors than your plan allows, the API returns a 403 Forbidden with code quota_exceeded.

Upgrading and quota increases

You can upgrade your plan or add billing details directly from workspace settings. If your workload requires higher burst rate limits or tailored enterprise terms, reach out via Troubleshooting / FAQ.

Monitoring usage

Check your current monthly event consumption and active pipeline counts anytime in the workspace dashboard or via the workspace metadata endpoint.
