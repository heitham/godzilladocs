Pipelines endpoint v2

\n

Create and manage pipelines programmatically. Base URL: https://api.godzilladocs.dev/v2.

\n\n

Create a pipeline

\n

POST /v2/pipelines

\n\n\n \n \n \n \n \n \n \n \n \n
NameTypeRequiredDescription
namestringYesHuman-readable pipeline name, unique per workspace.
source_connector_idstringYesID of the connector events are read from.
destination_connector_idstringYesID of the connector events are written to.
transformsarrayNoOrdered list of transform step definitions. Omit for a pass-through copy.
schedulestringNoCron expression. Omit for event-triggered (streaming) pipelines.
\n\n
\n
\n create-pipeline.sh\n bash\n \n
\n 
curl -X POST https://api.godzilladocs.dev/v2/pipelines \\\n  -H \"Authorization: Bearer $GODZILLA_API_KEY\" \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"name\": \"ingest-orders\",\n    \"source_connector_id\": \"conn_pg_orders\",\n    \"destination_connector_id\": \"conn_snowflake_dw\"\n  }'
\n
\n\n

List pipelines

\n

GET /v2/pipelines — cursor-paginated, see Rate limits for the pagination envelope.

\n\n

Pipeline states

\n

Returned pipelines include a state field of draft, active, or paused — see Pipelines for what each means.

\n\n
\n
Deleting a pipeline
\n

Deleting a pipeline does not delete its source or destination connectors, and does not delete events already written to the destination. In-flight runs are allowed to finish before deletion completes.
