Transforms endpoint v2

Manage transform steps that reshape, filter, and enrich events as they pass through a pipeline. Base URL: https://api.godzilladocs.dev/v2.

Create a transform step

POST /v2/transforms

Name Type Required Description
pipeline_idstringYesID of the pipeline this transform will be part of.
namestringYesHuman-readable transform name, unique within the pipeline.
typestringYesTransform type: filter, map, enrich, or flatten.
configobjectYesType-specific configuration details, e.g. filter conditions or mapping rules.
positionintegerNoPosition in the pipeline's transform chain (0-indexed). Defaults to appending at the end.
create-transform.sh bash 
curl -X POST https://api.godzilladocs.dev/v2/transforms \\\n  -H "Authorization: Bearer $GODZILLA_API_KEY" \\\n  -H "Content-Type: application/json" \\\n  -d '{\n    "pipeline_id": "pipe_orders_to_dw",\n    "name": "normalize-currency",\n    "type": "map",\n    "config": { "rules": [ { "field": "amount", "operation": "convert_currency" } ] }\n  }'

List transforms

GET /v2/pipelines/{pipeline_id}/transforms — cursor-paginated, see Rate limits & errors for the pagination envelope.

Returns an ordered array of transform steps for a pipeline in their execution sequence.

list-transforms.sh bash 
curl -X GET https://api.godzilladocs.dev/v2/pipelines/pipe_orders_to_dw/transforms \\\n  -H "Authorization: Bearer $GODZILLA_API_KEY"

Update a transform step

PATCH /v2/transforms/{id} — modify the configuration of an existing transform without reordering.

Only the config field may be updated. To reorder transforms within a pipeline, delete and recreate them at the desired position.

Delete a transform step

DELETE /v2/transforms/{id} — remove a transform from the pipeline. Other transforms shift positions automatically.

Pipeline redeployment

Modifying, creating, or deleting transforms triggers an automatic pipeline redeployment. In-flight events continue on the previous transform sequence; the new configuration takes effect on the next scheduled run or incoming trigger.
