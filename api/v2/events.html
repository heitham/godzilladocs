Events endpoint v2 withdrawn

Stability: Deprecated

v2 is no longer supported

The v2 events endpoint has been withdrawn and is no longer available. v2 no longer accepts requests to this endpoint.

If you're currently using v2 events, migrate to the v3 events endpoint immediately. See the v2→v3 migration guide for detailed upgrade steps.

Migrating from v2 events

The v2 events endpoint allowed you to query and replay events through GET /v2/pipelines/{pipeline_id}/events and POST /v2/events/{id}/replay.

v3 replaces both endpoints under a simpler, more consistent path structure:

  • GET /v2/pipelines/{pipeline_id}/events → GET /v3/pipelines/{pipeline_id}/events
  • POST /v2/events/{id}/replay → POST /v3/pipelines/{pipeline_id}/events/{event_id}/replay

Key differences:

  • Filtering: v2 filtered by type and occurred_at. v3 filters by status (success/failed/pending) and timestamp range (since/until).
  • Event status: v3 includes a status field on each event, making it clearer what happened during processing.
  • Replay path: v3 requires the pipeline ID in the replay endpoint for better API clarity.
Need help migrating?

Full migration details and code examples are in the v2→v3 migration guide. Visit the v3 events endpoint to learn about the new API.
