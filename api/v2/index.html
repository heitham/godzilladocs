v2 is no longer supported

The v2 API has been fully deprecated and all endpoints are offline. v2 no longer accepts any requests.

Migrate immediately to the v3 API. See the v2 → v3 migration guide for detailed upgrade instructions.

\n\n

API Reference (v2 — Offline)

This documentation is archived. The v2 API is no longer available.

Go to v3 API Reference
\n\n

Stability: Deprecated

\n\n
\n

Why v2 is offline

\n \n

v3 shipped with significant improvements to events filtering, error handling, and endpoint consistency. To ensure the reliability of the platform, v2 endpoints have been decommissioned.

\n\n

Migration required

\n\n

All v2 API users must migrate to v3. The main changes:

\n\n
    \n
  • Base URL: https://api.godzilladocs.dev/v2 → https://api.godzilladocs.dev/v3
    • \n
  • Events filtering: type parameter → status (success/failed/pending)
    • \n
  • Event replay: Path now includes pipeline ID: /v3/pipelines/{pipeline_id}/events/{id}/replay
    • \n
  • Error responses: Enhanced error details with request IDs for debugging
    • \n
\n\n

Read the full v2 → v3 migration guide →
