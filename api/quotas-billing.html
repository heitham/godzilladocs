Quotas & billing v2 Stable

Godzilla enforces resource quotas per workspace according to your plan tier. This page details plan limits, quota dimensions, and the exact platform behavior when an account exceeds its quota.

1,000
requests / minute (Standard Tier)

Default API rate limit per workspace. Enterprise plans support customized limits up to 50,000+ req/min.

Plan tiers

Each workspace is subscribed to one of three tiers. Quotas apply across all pipelines, connectors, and API keys created within that workspace.

Plan Tier API Rate Limit Monthly Events Active Pipelines Connectors Support SLA
Developer 100 req/min 50,000 2 3 Community
Standard 1,000 req/min 5,000,000 25 20 1 business day
Enterprise Custom (10,000+) Custom / Unlimited Unlimited Unlimited 24/7 dedicated (1 hr SLA)

Quota dimensions

Godzilla accounts are governed by four primary quota dimensions:

  • API request rate: Per-minute sliding window limits on calls to the Godzilla API (https://api.godzilladocs.dev/v2 and https://api.godzilladocs.dev/v3). See Rate limits for header specifications.
  • Monthly event volume: The total number of events ingested, transformed, and delivered by your pipelines in a monthly billing cycle.
  • Active pipeline concurrency: The maximum number of pipelines running in active state simultaneously. Pipelines in draft or paused state do not count toward this limit.
  • Dead-letter queue retention: How long failed events remain available for inspection and replay (7 days on Developer, 30 days on Standard, 90 days on Enterprise).

What happens when you exceed your quota

Platform behavior depends on which quota dimension is exceeded and your workspace billing settings:

1. API rate limit exceeded

When API request volume exceeds the per-minute threshold, the gateway immediately rejects additional requests with HTTP status 429 Too Many Requests. Responses include a Retry-After header indicating the number of seconds until the rate limit resets.

429-rate-limit-response.json json 
{
  "error": {
    "code": "rate_limit_exceeded",
    "message": "API rate limit of 1000 req/min exceeded. Retry after 12 seconds.",
    "request_id": "req_rl_4901b"
  }
}

2. Monthly event quota exceeded

When event processing approaches or passes the monthly quota:

  • Warning notifications: Godzilla issues automated webhook notifications (account.quota_warning at 80% and account.quota_exceeded at 100%) and sends email alerts to workspace admins.
  • Standard tier (auto-overage enabled): Pipelines continue processing without interruption. Overage events are billed at $0.25 per 100,000 events on your monthly invoice.
  • Developer tier & hard caps: If auto-overage is disabled or you are on the Developer tier, pipelines transition to paused state. In-flight events finish processing, while new incoming events are buffered up to connector queue limits before upstream reads pause.
No event drops on overage

Godzilla never silently drops events when an account exceeds its quota. Events either flow with overage pricing or pause safely at the connector stage until the plan is upgraded or the billing cycle rolls over.

3. Pipeline or connector limits exceeded

Attempting to create a pipeline or connector beyond your plan limit via POST /v3/pipelines or POST /v2/connectors returns 403 Forbidden with error code quota_exceeded.

quota-exceeded-response.json json 
{
  "error": {
    "code": "quota_exceeded",
    "message": "Maximum active pipeline limit (25) reached for this workspace. Upgrade your plan to create more pipelines.",
    "request_id": "req_lim_9921c"
  }
}

Upgrading and billing management

You can upgrade your plan or configure overage settings at any time:

  • Self-serve upgrades: Upgrade from Developer to Standard instantly in the workspace dashboard under Settings > Billing.
  • Enterprise custom plans: For custom rate limits, VPC peering, and enterprise volume discounts, contact our sales team at sales@godzilladocs.dev or via Troubleshooting / FAQ.
