Events endpoint v3 Stable

Query and replay events that have flowed through a pipeline. Base URL: https://api.godzilladocs.dev/v3.

New in v3: Enhanced filtering by event attributes, batch operations, and improved replay capabilities.

v2 withdrawn

v2 is no longer supported and will not accept new requests. All integrations must migrate to v3. See the migration guide for upgrade instructions.

List events

GET /v3/pipelines/{pipeline_id}/events — cursor-paginated with enhanced filtering by event attributes.

Name Type Required Description
typestringNoFilter to a single event type, e.g. order.created.
sincestringNoISO-8601 timestamp lower bound on occurred_at.
untilstringNoISO-8601 timestamp upper bound on occurred_at (new in v3).
statusstringNoFilter by event status: pending, delivered, failed, or dead-lettered (new in v3).
cursorstringNoOpaque pagination cursor from a previous response's next_cursor.
event.json json 
{\n  \"id\": \"evt_8f2c1a90\",\n  \"type\": \"order.created\",\n  \"occurred_at\": \"2026-08-18T09:12:44Z\",\n  \"status\": \"delivered\",\n  \"payload\": { \"order_id\": \"ord_4471\" }\n}

Replay a dead-lettered event

POST /v3/events/{id}/replay — re-runs an event that exhausted its retries from where it was dead-lettered. See the Error handling & recovery guide for when to use this versus reprocessing an entire time range.

Batch replay

POST /v3/pipelines/{pipeline_id}/events/replay-batch — replay multiple dead-lettered events matching a filter (new in v3).

Name Type Required Description
typestringNoReplay only events of this type.
sincestringNoReplay events from this ISO-8601 timestamp onward.
untilstringNoReplay events up to this ISO-8601 timestamp.
Platform events

Lifecycle notifications like pipeline.started and connector.error are not returned by this endpoint — subscribe to them through the Webhooks endpoint instead.

Related concepts

Learn more about what events are and how they work in the Events concept guide. Also see Schemas for validating event payloads and Error handling & recovery for working with dead-lettered events.
