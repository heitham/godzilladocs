Transforms endpoint v2

Create and list transform steps within pipelines. Base URL: https://api.godzilladocs.dev/v2.

Create a transform step

POST /v2/pipelines/{pipeline_id}/transforms

Name Type Required Description
namestringYesHuman-readable transform step name.
typestringYesOne of jq, javascript, or python.
expressionstringYesThe transform expression in the language specified by type.
positionintegerNoOrder in the transform chain (0-indexed). Defaults to appending at the end.
create-transform.sh bash 
curl -X POST https://api.godzilladocs.dev/v2/pipelines/pipe_abc123/transforms \
  -H "Authorization: Bearer $GODZILLA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "extract-user-id",
    "type": "jq",
    "expression": ".user_id = (.user | .id)"
  }'

List transform steps

GET /v2/pipelines/{pipeline_id}/transforms — returns an array of all transform steps for the pipeline in execution order.

list-transforms.sh bash 
curl -X GET https://api.godzilladocs.dev/v2/pipelines/pipe_abc123/transforms \
  -H "Authorization: Bearer $GODZILLA_API_KEY"

Transform languages

Each transform step supports a different expression language for manipulating events in flight:

  • jq — JSON query and transformation language. Best for selecting, filtering, and mapping fields.
  • javascript — Run arbitrary JavaScript code against events. Use for complex business logic and stateful transformations.
  • python — Run Python 3 code. Useful for mathematical operations and calling external libraries.
Transform execution order

Transforms execute sequentially in position order. The output of one transform becomes the input to the next. Design transform chains to avoid unnecessary data duplication or computational overhead.
