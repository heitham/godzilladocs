Transforms endpoint v2

\n

Create and manage transform steps that modify events as they flow through a pipeline. Base URL: https://api.godzilladocs.dev/v2.

\n\n

Create a transform

\n

POST /v2/transforms

\n\n\n \n \n \n \n \n \n \n \n \n
NameTypeRequiredDescription
pipeline_idstringYesID of the pipeline this transform step belongs to.
namestringYesHuman-readable transform name, unique within the pipeline.
typestringYesOne of filter, map, enrich, or aggregate.
configobjectYesType-specific configuration, e.g. filter expression or mapping rules.
positionintegerNoOrder within the pipeline's transform sequence (0-indexed). Defaults to end of sequence.
\n\n
\n
\n create-transform.sh\n bash\n \n
\n 
curl -X POST https://api.godzilladocs.dev/v2/transforms \\\n  -H \"Authorization: Bearer $GODZILLA_API_KEY\" \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"pipeline_id\": \"pl_ingest_orders\",\n    \"name\": \"filter-high-value\",\n    \"type\": \"filter\",\n    \"config\": { \"expression\": \"amount > 1000\" }\n  }'
\n
\n\n

List transforms

\n

GET /v2/transforms?pipeline_id={pipeline_id} — returns all transform steps for a pipeline, ordered by their position in the sequence.

\n\n
\n
\n list-transforms.sh\n bash\n \n
\n 
curl https://api.godzilladocs.dev/v2/transforms?pipeline_id=pl_ingest_orders \\\n  -H \"Authorization: Bearer $GODZILLA_API_KEY\"
\n
\n\n

Transform types

\n

Each transform type accepts a different config object shape:

\n\n
    \n
  • filter — expression string with a boolean condition that determines which events pass through.
    • \n
  • map — rules object mapping source fields to destination fields or computed values.
    • \n
  • enrich — source connector ID and lookup_field for joining external data.
    • \n
  • aggregate — group_by fields and aggregations array defining the output schema.
    • \n
\n\n
\n
Transform order matters
\n

Transforms are applied in sequence based on their position. A filter applied before a map sees the original event structure; the same filter after the map sees the mapped fields.
