Transforms endpoint v2 Stable

Manage intermediate transform steps that reshape, filter, or enrich events in a pipeline. Transform output payloads are validated against configured schemas.

Create a transform step

POST /v2/pipelines/{pipeline_id}/transforms

Name Type Required Description
typestringYesOne of reshape, filter, enrich.
configobjectYesType-specific configuration (e.g. rename rules, filter conditions, or enrichment fields).
orderintegerNo0-indexed position in the transform pipeline. Defaults to appending to the end.
create-transform.sh bash 
curl -X POST https://api.godzilladocs.dev/v2/pipelines/pl_ingest_orders/transforms \
  -H "Authorization: Bearer $GODZILLA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "filter",
    "config": {
      "condition": "payload.amount_cents > 0"
    }
  }'

List transform steps

GET /v2/pipelines/{pipeline_id}/transforms — returns the ordered list of transform steps configured for a pipeline.

list-transforms-response.json json 
{
  "data": [
    {
      "id": "tr_filter_orders",
      "pipeline_id": "pl_ingest_orders",
      "type": "filter",
      "order": 0,
      "config": { "condition": "payload.amount_cents > 0" }
    },
    {
      "id": "tr_reshape_orders",
      "pipeline_id": "pl_ingest_orders",
      "type": "reshape",
      "order": 1,
      "config": { "rename": { "customer_email": "email" }, "drop": ["raw_ip"] }
    }
  ]
}
Order of execution

Transforms run sequentially in order. Placing filter steps before reshape or enrichment steps prevents unnecessary processing on events that will be dropped.
