API Reference

Every endpoint in the Godzilla REST API, with request/response examples.

Start with Pipelines

All endpoints require a bearer API key. The pipelines and events endpoints are on v3 (https://api.godzilladocs.dev/v3), while all other endpoints currently live under https://api.godzilladocs.dev/v2. New to the platform? Learn the core data model in Concepts and read Authentication in Getting Started first.
