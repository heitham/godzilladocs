Events endpoint v3

Stability: Stable

Query and replay events that have flowed through pipelines. Base URL: https://api.godzilladocs.dev/v3.

v3 is the current API version. The v2 events endpoint has been withdrawn. If you're still on v2, see the v2→v3 migration guide to upgrade.

Query events

GET /v3/pipelines/{pipeline_id}/events — cursor-paginated event search with optional filtering by timestamp and status.

Query parameters:

Name Type Required Description
statusstringNoFilter by success, failed, or pending.
sinceISO 8601 timestampNoEvents after this timestamp.
untilISO 8601 timestampNoEvents before this timestamp.
page_sizeintegerNo1–100, defaults to 20.
cursorstringNoOpaque pagination cursor from a previous response's next_cursor.

Replay an event

POST /v3/pipelines/{pipeline_id}/events/{event_id}/replay — reprocess a single event through the pipeline from scratch.
