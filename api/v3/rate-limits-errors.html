Limits, quotas & errors v3

Stability: Stable

v3 is the current API version. v2 docs remain available for users still on the previous version.

Rate limits

Standard-tier accounts are rate-limited to 1,000 requests per minute per workspace. The remaining quota is returned in the X-RateLimit-Remaining response header.

Pagination

All list endpoints use cursor-based pagination. Responses include:

{{ds:component/code-block|language=json|code={ "items": [...], "pagination": { "next_cursor": "abc123def456", "has_more": true } }}}

Pass the next_cursor to the cursor query parameter to fetch the next page. The page_size parameter (1–100, defaults to 20) controls results per page.

Error responses

Errors are returned with a non-2xx status and include:

{{ds:component/code-block|language=json|code={ "error": { "code": "VALIDATION_ERROR", "message": "Request failed validation", "details": { "fields": { "name": "Pipeline name is required" } } } }}}

Common error codes:

  • VALIDATION_ERROR (400) — Request body failed validation
  • NOT_FOUND (404) — Resource does not exist
  • CONFLICT (409) — Resource already exists (e.g., duplicate pipeline name)
  • RATE_LIMITED (429) — Rate limit exceeded; retry after the Retry-After header
  • INTERNAL_ERROR (500) — Unexpected server error
