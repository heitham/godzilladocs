Transforms endpoint v3

Create and manage transform steps that reshape, filter, and enrich events. Base URL: https://api.godzilladocs.dev/v3.

v3 is the current API version. v2 docs remain available for users still on the previous version.

Create a transform

POST /v3/pipelines/{pipeline_id}/transforms

Name Type Required Description
typestringYesTransform type (e.g., filter, map, aggregate).
configobjectYesType-specific configuration object.
positionintegerNoPosition in the transform chain (0-indexed).

List transforms

GET /v3/pipelines/{pipeline_id}/transforms — returns all transforms for a pipeline in execution order.
