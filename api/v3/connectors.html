Connectors endpoint v3

Stability: Stable

Create and manage connectors programmatically. Base URL: https://api.godzilladocs.dev/v3.

v3 is the current API version. v2 docs remain available for users still on the previous version.

Create a connector

POST /v3/connectors

Name Type Required Description
namestringYesHuman-readable connector name, unique per workspace.
typestringYesConnector type (e.g., postgres, snowflake, kafka).
credentialsobjectYesType-specific credential object (e.g., host, port, username).

List connectors

GET /v3/connectors — cursor-paginated with the same pagination envelope as pipelines.

Rotate credentials

POST /v3/connectors/{connector_id}/rotate-credentials — safely update a connector's credentials without interrupting pipelines using it.
