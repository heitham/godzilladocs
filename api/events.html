Events endpoint v2 withdrawn Deprecated

v2 is no longer supported

v2 of the Events endpoint was withdrawn on 2026-08-21. All integrations must migrate to v3 Events endpoint immediately. v2 endpoints no longer accept requests.

See the migration guide (v2 → v3) for step-by-step upgrade instructions.

Why v2 was withdrawn

v3 addresses critical limitations in v2:

  • Better filtering: Filter events by status and time range in a single request instead of fetching all events.
  • Batch operations: Replay multiple dead-lettered events at once with replay-batch.
  • Improved reliability: Enhanced error handling and event state tracking.

Migration

The v3 API is largely compatible with v2 — most migrations require only path and parameter updates. See the migration guide for the full list of changes and code examples.
