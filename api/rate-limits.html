Rate limits v2 Stable

API rate limits are enforced per workspace using a 60-second sliding window. Limits apply across all pipelines, connectors, and API keys created within the workspace.

100
requests / minute (Developer)

Rate limit for Developer tier API keys per workspace.

1,000
requests / minute (Standard)

Default rate limit for Standard tier API keys per workspace. See Quotas & billing for all plan tiers.

10,000+
requests / minute (Enterprise)

Customizable rate limits for Enterprise plans up to 50,000+ req/min.

Rate limits by plan tier

The table below summarizes the API rate limits and enforcement behavior for each plan tier:

Plan Tier API Rate Limit Window Status Code on Breach
Developer 100 req/min 60-second sliding window 429 Too Many Requests
Standard 1,000 req/min 60-second sliding window 429 Too Many Requests
Enterprise Custom (10,000+) 60-second sliding window 429 Too Many Requests

Rate limit headers

Every response includes X-RateLimit-Limit, X-RateLimit-Remaining, and X-RateLimit-Reset. A request over the limit returns 429 Too Many Requests with a Retry-After header.

Header Type Description
X-RateLimit-Limit integer The maximum number of requests allowed in the current 60-second sliding window.
X-RateLimit-Remaining integer The number of remaining requests permitted within the current window.
X-RateLimit-Reset integer Unix timestamp (in seconds) indicating when the current sliding rate limit window resets.
Retry-After integer Number of seconds to wait before retrying when a 429 Too Many Requests response is returned.
Need higher limits or hitting quota caps?

If your integration frequently encounters 429 Too Many Requests responses or exceeds monthly event volume, see Quotas & billing to compare plan tiers and understand what happens when quotas are exceeded.

Pagination

List endpoints (Pipelines, Connectors, Events) use cursor-based pagination — a departure from v1's offset-based pagination.

list-response.json json 
{
  "data": [ { "id": "pl_ingest_orders" } ],
  "next_cursor": "eyJvZmZzZXQiOjIwfQ",
  "has_more": true
}
