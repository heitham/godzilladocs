Rate limits v3

1,000
requests / minute

Default rate limit for standard-tier API keys, per workspace. See Quotas & billing for plan tiers and quota details.

Rate limit headers

Every response includes three headers showing your current rate-limit status:

X-RateLimit-Limit

Your per-minute request allowance (e.g., 1000)

X-RateLimit-Remaining

Requests remaining in the current minute (e.g., 847)

X-RateLimit-Reset

Unix timestamp when the window resets (e.g., 1704067200)

A request over the limit returns 429 Too Many Requests with a Retry-After header indicating how many seconds to wait before retrying.

rate-limit-headers.txt text 
X-RateLimit-Limit: 1000
X-RateLimit-Remaining: 847
X-RateLimit-Reset: 1704067200

Pagination

List endpoints (Pipelines, Connectors, Events) use cursor-based pagination — a departure from v1's offset-based pagination.

list-response.json json 
{\n  "data": [ { "id": "pl_ingest_orders" } ],\n  "next_cursor": "eyJvZmZzZXQiOjIwfQ",\n  "has_more": true\n}
