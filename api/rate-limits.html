Rate limits v2 Stable

1,000
requests / minute

Default rate limit for standard-tier API keys, per workspace.

429
Too Many Requests

HTTP status code returned when rate limit is exceeded.

X-RateLimit-Reset
response header

Unix timestamp indicating when the limit resets.

For quota and billing information: See Quotas & billing to learn about plan tiers, monthly request limits, and what happens when you exceed your quota.

Rate limit headers

Every response includes X-RateLimit-Limit, X-RateLimit-Remaining, and X-RateLimit-Reset. A request over the limit returns 429 Too Many Requests with a Retry-After header.

Pagination

List endpoints (Pipelines, Connectors, Events) use cursor-based pagination — a departure from v1's offset-based pagination.

list-response.json json 
{\n  "data": [ { "id": "pl_ingest_orders" } ],\n  "next_cursor": "eyJvZmZzZXQiOjIwfQ",\n  "has_more": true\n}
